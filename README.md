# ЛРМ(π). Модельный эксперимент

Материалы к статье Д. И. Галеева, Г. Р. Галеевой, В. Ю. Бодрякова «Формирование алгоритмического мышления обучающихся при вайб-кодинге в математическом эксперименте с известным ответом» (журнал «Учебный эксперимент в образовании»).

## Состав

- `lrm_pi_model.py` выполняет пиксельный подсчёт для 18 радиусов, оценку коэффициента k методом наименьших квадратов, сравнение с методом Монте-Карло (зерно 2026) и строит рисунки статьи
- `данные_модельного_эксперимента.csv` содержит выдачу программы (R, S_inn, S_out, ⟨S⟩, δS и варианты соглашений)

## Запуск

```bash
pip install -r requirements.txt
python lrm_pi_model.py out
```

Программа детерминирована. Она проверяет тождества S_out − S_inn = 8R + 4 и ⟨S⟩ = N(R) + 1, печатает оценки k по накапливаемым данным бригад и сохраняет рисунки в папку `out`.

## Использование ИИ

Код подготовлен с помощью ИИ-ассистента Claude (Anthropic) по техническому заданию авторов и проверен по ручному подсчёту пикселей для R = 4 и R = 6 и по тождеству S_out − S_inn = 8R + 4.
