# ЛРМ(π). Модельный эксперимент

Материалы к статье Д. И. Галеева, Г. Р. Галеевой, В. Ю. Бодрякова «Формирование алгоритмического мышления обучающихся при вайб-кодинге в математическом эксперименте с известным ответом» (журнал «Учебный эксперимент в образовании»).

## Состав

- `lrm_pi_model.py` разыгрывает 18 случайных радиусов из диапазона 4 ≤ R ≤ 38 (шесть бригад по три круга), считает внутреннюю и внешнюю пиксельные оценки площади круга по точным формулам и прямым перебором пикселей, оценивает коэффициент k методом наименьших квадратов, сравнивает результат с методом Монте-Карло и строит рисунки статьи
- `данные_модельного_эксперимента.csv` содержит выдачу программы (R, S_inn, S_out, ⟨S⟩, δS, отклонение от πR², выдачу программы с ошибкой в границе цикла и подсчет по центрам пикселей)

## Точные формулы

Для четверти круга радиуса R > 0 с центром в узле сетки

S_inn = Σ_{k=1}^{[R]} [√(R² − k²)],  S_out = Σ_{k=0}^{[R]} ([√(R² − k²)] + 1),

где [x] есть целая часть числа x (Бодряков В. Ю., Быков А. А., «Математическое образование», 2019, № 4 и 2020, № 1). Для всего круга результат учетверяется, и выполняется тождество S_out − S_inn = 8[R] + 4.

## Запуск

```bash
pip install -r requirements.txt
python lrm_pi_model.py out
```

Программа детерминирована, радиусы и точки метода Монте-Карло порождаются генератором с зерном 2026. Она проверяет совпадение перебора с точными формулами и тождество, печатает оценки k по накапливаемым данным бригад, результаты программ с типичными ошибками и сохраняет рисунки в папку `out`.

## Использование ИИ

Код подготовлен с помощью ИИ-ассистента Claude (Anthropic) по техническому заданию авторов и проверен по ручному подсчету пикселей для R = 4,5 и R = 6,5 и по точным формулам.
